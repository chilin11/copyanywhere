手机、Mac、Windows 之间互传文字、截图和文件，不在同一个网络也能用。

在同一服务器使用相同 Token 的设备共享内容。在已连接的设备选择「添加设备」获取 Token 或链接。

Token 等同私钥，只发给自己的设备；它不是服务器创建密码。

服务器创建密码仅用于创建，和用于连接及加密的 Token 不同。

  • 端到端加密在本机加密后才上传，服务器只存密文
  • 实时同步一台设备发送，其他设备立刻收到
  • 用完即焚到期自动删除，也可随时清空

已经连接过？在那台设备上点右上角 ＋ 添加设备，扫码或复制 Token 加入。iPhone 主屏幕 App 可能需要重新连接。

添加设备

iPhone 主屏幕 App 可在 App 内粘贴 Token 或链接。

Token 等同私钥，二维码和链接也包含 Token；只发给自己的设备，不要公开展示。它不是服务器创建密码。

在同一服务器扫码，或复制 Token / 链接到另一台设备。

对方看不到？

  1. 服务器和 Token 是否一致 确认两台设备连接同一服务器并使用相同 Token。短指纹仅供参考，不是完整 Token；相同也不能证明 Token 一致。
  2. 对方在线吗 只有本机 → 另一台可能没有打开页面，或使用了不同的服务器或 Token。
  3. 实时通道通吗 不通通常是反向代理缓冲了事件流，内容仍会在几秒内出现。复制诊断信息发给管理员。
连接诊断

诊断信息不含 Token、完整内部 ID 或任何内容。

设置

退出只清除本设备上的 Token，其他设备不受影响。删除会立即删除服务器上当前 Token 对应的全部密文，使用此 Token 的所有设备都会失效。

更换 Token

请输入同一服务器上已有的 Token 或原配对链接。切换前请备份当前 Token；切换不会删除服务器数据。

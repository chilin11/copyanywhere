# CopyAnywhere

自托管、**端到端加密**的跨设备剪贴板 / 文件传输。手机、Mac、Windows 各开一个网页，不在同一个网络也能互传文字、截图和文件。

- **服务器看不到内容**：内容在浏览器里用 AES-256-GCM 加密后才上传。密钥只存在于配对链接的 `#` 片段和各设备本地，浏览器不会把 `#` 后面的部分发给服务器。文件名、类型、设备名也一起加密。
- **任何网络都能用**：只需要能访问你的 VPS（HTTPS），不需要 TURN、不需要客户端。
- **用完即焚**：默认 24 小时后自动删除；可以手动删除单条、清空，或删除整个空间。
- **零依赖**：Node 内置模块，一个容器，以非 root 用户运行，根文件系统只读。

## 部署（VPS）

需要 Docker（含 Compose v2），以及一个指向 VPS 的域名。

```bash
git clone <this repo> copyanywhere && cd copyanywhere
sudo ./install.sh drop.example.com   # 已装 Caddy：自动加站点和 HTTPS
# 或者 ./install.sh                   # 只启动服务，监听 127.0.0.1:8090，反代自己配
```

脚本会生成 `.env`（包含随机的服务器密码），构建并启动容器，最后打印出密码。

- **Caddy**：`drop.example.com { reverse_proxy 127.0.0.1:8090 }`
- **Cloudflare Tunnel**：Public Hostname 指向 `http://127.0.0.1:8090`。免费版请求体上限是 100MB，所以 `MAX_FILE_MB` 要保持在 95 以下。
- **更新**：`git pull && ./install.sh`
- **日志**：`docker compose logs -f`

配置见 `.env.example`：保存时长、单文件上限、空间容量上限和条数上限。

## 使用

1. 电脑打开 `https://drop.example.com`，输入服务器密码，**创建空间**。
2. 弹出二维码后，手机扫码即可加入。其他电脑可以把「复制链接」发给自己，然后打开。
3. 之后在任一设备上：
   - **发送**：在页面任意位置按 Ctrl/⌘+V，粘贴的文字、截图、文件会直接加密发送；也可以拖拽文件，或者点「粘贴剪贴板」「文件 / 照片」。
   - **接收**：内容实时出现，点「复制」「复制图片」「下载」即可。手机上的图片可以「分享 / 存到相册」。
4. **Android**：在 Chrome 里把网页「添加到主屏幕」。之后在相册、文件或任意 App 里点「分享 → CopyAnywhere」，就能直接发送。
5. **iPhone**：Safari 里点「添加到主屏幕」。iOS 不支持网页出现在分享菜单里，所以要打开它，再点「粘贴剪贴板」或「文件 / 照片」。

> 手机系统不允许网页或 App 在后台读取剪贴板，所以「复制完别的设备自动就有」只能在发出方手动点一次发送，任何工具都绕不开这一点。

## 安全模型

| 谁 | 能看到什么 |
|---|---|
| VPS / 服务器管理员 | 只有密文、密文大小、上传时间。看不到内容、文件名、设备名，也拿不到密钥 |
| 拿到配对链接的人 | 能看到这个空间里的全部内容。**链接就是钥匙，只发给自己的设备** |
| 不知道服务器密码的人 | 不能创建空间（密码错误 10 次 / 15 分钟后会被限流） |

- 空间 ID 由密钥经 HKDF 单向派生，服务器无法反推出密钥。
- 每条内容使用独立的随机 IV，并通过 AAD 绑定到它的元数据，防止被替换或挪用。
- 严格的 CSP（禁止内联脚本、只允许同源连接）、`Referrer-Policy: no-referrer`，服务器不记录访问日志。
- 网页端加密有一个固有前提：你要信任服务器发下来的 JS。因为服务器是你自己的，这一点成立。
- 想让某台设备失效：在那台设备上点「退出」；如果怀疑链接已经泄露，就「删除整个空间」，再重新创建一个。
